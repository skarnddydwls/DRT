# 정류장 주변 관광지 등록

1. 센터 http://localhost:3000/tourism 에서 운영관리 → 주변 관광지 관리를 엽니다.
2. 위쪽 정류장명 입력칸으로 검색한 뒤 작은 정류장 목록에서 행을 선택합니다. 목록에는 `USE_YN='Y'`인 정류장만 표시됩니다. 아래 관광지 목록의 '추가' 버튼으로 장소 이름·분류·주소·소개·사진을 입력합니다.
3. 표시 순서는 작은 숫자가 먼저입니다. 저장하면 해당 정류장과 연결됩니다.
   같은 이름의 정류장은 목록에 한 번만 표시되며, 등록된 관광지는 같은 이름의 양쪽 방향 정류장에서 공통으로 조회됩니다. 기존에 한 방향에 등록한 관광지도 공유되고, 수정·숨김은 양방향에 함께 적용됩니다. 정류장명은 앞뒤 공백을 제외한 정확한 이름으로 묶습니다.
4. 승객 앱 정류장 선택 화면에서 하차 정류장을 기준으로 표시합니다. 하차를 아직 선택하지 않았다면 승차 정류장을 기준으로 표시합니다.
5. 주변 정류장 지도에서 정류장을 선택해도 도착정보 아래에서 확인할 수 있습니다.

사진은 JPG·PNG, 최대 5MB·2,400만 화소·가로/세로 8,000px입니다. 사진 없이도 등록할 수 있습니다. 사진과 장소 정보는 서버 PostgreSQL의 `drt.station_attraction` 테이블에 저장되므로 다른 기기에서도 같은 내용을 봅니다. 사진을 바꾸지 않고 수정하면 기존 사진이 유지됩니다. '기존 사진 제거'로 사진만 없앨 수 있습니다.

'승객 앱에 표시'를 해제하면 장소와 사진이 공개 조회에서 제외됩니다. 데이터를 삭제하지 않아 다시 표시할 수 있습니다. 등록된 장소가 없는 정류장에는 관광지 영역 자체를 표시하지 않습니다. 실제 콘텐츠는 임의로 등록하지 않았습니다.

앱에 새 등록 내용을 반영하려면 화면에 다시 들어가거나 새로고침하세요. 관광지 조회 오류는 예약과 버스 도착정보 조회를 막지 않습니다.

## 운영 서버 전환 시 필수 사항

현재 센터에는 정식 관리자 인증이 없습니다. 관광지 관리 API는 localhost 센터와 동일 PC의 백엔드 요청으로 제한한 **로컬 개발용**입니다. 인터넷·공유망에 공개하지 마세요. 실제 운영 전 센터 관리자 로그인·권한 검사·CSRF 보호를 추가하고 이 제한을 인증 기반으로 교체해야 합니다. 이미지 공개 조회는 활성화된 장소만 허용합니다.

DB 스키마: 백엔드 `docs/station-attractions.sql`. 기존 예약/회원/정류장 데이터를 변경하지 않는 별도 추가 테이블입니다. 모바일 기기는 기존 `EXPO_PUBLIC_API_URL`을 PC/운영 백엔드 주소로 설정해야 합니다.
